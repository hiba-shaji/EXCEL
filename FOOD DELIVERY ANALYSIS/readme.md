Food Delivery Analysis Dashboard

An interactive Food Delivery Analysis Dashboard built using Microsoft Excel and Power Query to analyze restaurant performance, customer ratings, delivery trends
and order data.

Key Features:
Interactive KPI cards for key performance metrics
Restaurant-wise performance analysis
Customer rating analysis
Order and revenue trends
Interactive slicers and filters
Data cleaning and transformation using Power Query
Pivot tables and charts for data visualization

Tools Used:
Microsoft Excel | Power Query | Pivot Tables | Data Visualization
